Medium Import Hilfe

Import Hilfe

  • Für Zeilen-Import (Row Import) Vorschau nur den 'Abschicken' Knopf anklicken ohne eine Datei auszuwählen.
  • Medien-Typ auswahl wird von XML-Import PlugIns ignoriert.
  • Eigentümerangaben der Importquelle werden während des Importprozesses ignoriert.

Zeilen-Import Hilfe

  • Der Medien-Typ ist die Datenspalte, die den jeweiligen Medientyp (CD,VHS,VCD,DVD,etc) spezifiziert. Die Datenreihen werden nur auf jene Reihen eingeschränkt, die dem vorgewählten Medien-Typ entsprechen.
  • Damit der Import richtig funktioniert, muss der Datenwert der Spalte value und nicht von display aus der Tabelle 's_attribute_type_lookup' eingegeben werden. Andernfalls gibt es keinen Treffer.
  • Die Standardwerte werden nur angewendet, wenn eine Datenspalte nicht von der Import-Datei gewählt wurde.
  • Wenn Sie keine Kategorie spezifizieren, wird eine leere Kategorie eingefügt.
  • Die Option 'Mit Großbuchstaben beginnen' wandelt alles - bis auf den ersten Buchstaben in jedem Wort - in Kleinbuchstaben. Römische Ziffern werden nicht geändert.

XML-Import Hilfe

  • Der Status-Typ Wert wird verwendet, wenn:
    • kein Status-Typ angegeben wurde
    • der übergebene Status-Typ falsch ist
    • die Option Status Typ deaktivieren NICHT ausgewählt ist
  • Anwählen der Option Status Typ deaktivieren bewirkt, dass der der jeweilige Status Typ aus der Import-Quelle ignoriert wird.
